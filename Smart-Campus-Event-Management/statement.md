# Project Statement

## Problem Statement
College event participation is often tracked through disconnected spreadsheets, forms and manual records. This makes it difficult to prevent duplicate registrations, enforce event capacity, track attendance and generate reliable participation records.

## Scope
The project provides a terminal-based Java application for managing the complete event participation lifecycle: student records, event records, registration, attendance, certificates and analytics. It uses CSV files for lightweight persistence and is intentionally designed so the storage layer can later be replaced by a database.

## Target Users
- Students
- Event organizers
- Faculty coordinators

## High-Level Features
1. Student management
2. Event management
3. Registration and cancellation
4. Attendance management
5. Certificate management
6. Reports and analytics
